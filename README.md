# Tugas Rutin 10 — Blog CRUD Laravel

## Deskripsi
Proyek ini dibuat untuk memenuhi tugas Tugas Rutin 10,
yaitu membangun aplikasi Blog CRUD menggunakan Laravel.

Aplikasi ini memungkinkan pengguna mengelola artikel blog
melalui fitur Create, Read, Update, dan Delete (CRUD).

## Teknologi
- Laravel 12
- PHP 8.4
- MySQL
- Blade Template
- HTML dan CSS

## Fitur
- Menampilkan daftar artikel
- Menambahkan artikel
- Melihat detail artikel
- Mengedit artikel
- Menghapus artikel
- Pencarian artikel berdasarkan judul atau penulis
- Pagination
- Validasi input
- Flash message
- Blade Layout
- Blade Components (Alert dan Card)
- CSRF Protection
- Route Model Binding
